==============================================================================
ΒΗΜΑΤΑ ΕΚΚΙΝΗΣΗΣ ΣΤΟΝ SERVER
==============================================================================
Docker (προτεινόμενο):
  1. cp deploy/.env.production.example deploy/.env   (συμπλήρωσε τα μυστικά)
  2. npm run docker:up
  3. npm run docker:down                             (για σταμάτημα)

Bare-metal / PM2:
  1. npm ci
  2. npm run build
  3. npm run serve:prod        (ή: pm2 start deploy/ecosystem.config.js)

Έλεγχος μετά το deploy:
  curl -fsS https://<domain>/api/health
  curl -s -o /dev/null -w '%{http_code}\n' https://<domain>/api/admin/config   → 401
